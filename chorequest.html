Project Overview

Making everyday responsibilities more engaging.

ChoreQuest AI explores a practical application of agentic AI: coordinating family responsibilities while adapting suggestions to individual capacity, preferences, and engagement.

The Problem

Traditional chore trackers rely on static assignments and reminders. They may not account for workload, preferences, motivation, or changes in engagement over time.

The Approach

Separate task coordination from motivational recommendations. Allow specialized agents to request structured application data and actions through MCP tools.

The Experience

Provide a family-friendly interface for tasks, completion tracking, points, and experience-based rewards such as movie night or choosing dinner.

Agent Responsibilities

Two agents. Distinct responsibilities.

Separating task assignment from engagement analysis makes agent behavior easier to understand, test, and evolve.

01. Orchestrator Agent

Coordinates task allocation by evaluating available chores and relevant family context.

  • Retrieve pending tasks.
  • Check user capacity and preferences.
  • Consider assignment history.
  • Recommend suitable assignments.
  • Invoke assignment tools.
Task Allocation Capacity Awareness Coordination

02. Motivator Agent

Examines engagement patterns and helps personalize encouragement and rewards.

  • Retrieve engagement metrics.
  • Review task completion trends.
  • Identify potential disengagement signals.
  • Suggest non-monetary rewards.
  • Support points-based recognition.

Model Context Protocol

Six tools connecting agents to actions.

MCP provides a structured interface between agent reasoning and application capabilities, reducing the need for agents to manipulate application state directly.

list_tasks

Retrieves task information, including tasks available for assignment.

assign_task

Associates a task with a selected family member.

get_user_capacity

Retrieves capacity information to help avoid uneven workloads.

get_engagement_metrics

Provides engagement information for motivational analysis.

suggest_reward

Generates or retrieves suitable experience-based reward suggestions.

update_points_ledger

Records points-related changes associated with task completion and recognition.

Engineering principle: Agent decisions and state-changing operations should be separated through explicit tool contracts, input validation, and observable execution results.
End-to-End Flow

A representative workflow for assigning pending chores using structured application context and agent coordination.

Engineering Perspective

Design choices and tradeoffs.

The project provides a practical environment for exploring how agent-based applications can be organized into understandable, testable components.

Specialized Agents

Separating assignment and motivation reduces responsibility overlap, although coordination between agents adds orchestration complexity.

Explicit Tool Contracts

MCP tools create a clear interface between agent reasoning and application operations. Input validation remains important for state-changing actions.

Shared Application State

Shared task and engagement information supports coordination. Consistency, concurrent updates, and data persistence become important as usage grows.

Human-Centered Rewards

Experience-based rewards emphasize family engagement rather than treating every completed task as a financial transaction.

Observability

Agent execution traces, tool invocation results, and failure handling are important areas for reliable AI application engineering.

Responsible Evolution

The design provides a foundation for evaluating privacy, agent reliability, workload fairness, and safeguards before broader deployment.
